How to Install CaptiOCR

On Windows

  1. Download CaptiOCR-v__WINDOWS_VERSION__-installer.msi (or the portable .exe) from the release page.
  2. Run the installer, or start the portable .exe directly.
  3. On first launch CaptiOCR checks for Tesseract OCR and offers to download it from the official source if it is missing.
  4. Turn on live captions in your meeting app, select the caption area and start capturing.

On macOS

  1. Download CaptiOCR-v__MACOS_VERSION__-macos-arm64.dmg from the release page.
  2. Open the .dmg and drag CaptiOCR into the Applications folder.
  3. Enable CaptiOCR in System Settings › Privacy & Security › Screen & System Audio Recording, then restart the app.
  4. If macOS blocks the first launch, open System Settings › Privacy & Security and choose Open Anyway.
  5. Keep the caption window on the primary (menu-bar) display, select the caption area and start capturing.

Verify Your Download

Every release ships a SHA256SUMS.txt file. Compare it with the hash of the file you downloaded:

Windows (PowerShell)

Get-FileHash .\CaptiOCR-v*-installer.msi -Algorithm SHA256

macOS (Terminal)

shasum -a 256 CaptiOCR-v*-macos-arm64.dmg

Download FAQ

Does CaptiOCR run on Intel Macs?

Not at the moment. The macOS build is provided for Apple Silicon (arm64) Macs only.

Is there a Linux version of CaptiOCR?

There is no packaged Linux release. Linux support is experimental and requires running CaptiOCR from source with Python 3.9+ and Tesseract OCR installed.

Why are the Windows and macOS version numbers different?

The macOS port has its own release line (tags starting with macos-v) and is published independently from the Windows releases, so the two versions can differ and features may reach Windows first.

How do I update CaptiOCR?

CaptiOCR checks GitHub Releases for a newer version of your platform on startup. To update, download the new release from this page and install it over the previous version.
